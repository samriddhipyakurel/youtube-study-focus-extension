# 🎓 YouTube & Web Study Focus Mode (Chrome Extension - Manifest V3)

A Chrome & Arc Browser Extension designed to eliminate distractions, block social media apps, filter YouTube for **Math, DSA, Python, Problem Solving, Study Motivation, and Music ONLY**, and boost focus with an integrated Pomodoro timer.

---

## ✨ Key Features

1. **Strict YouTube Topic Filter (Math, DSA, Python, Motivation & Music ONLY)**:
   - Only allows videos related to:
     - 📐 **Math** (Calculus, Algebra, Geometry, Statistics, Linear Algebra)
     - 💻 **DSA** (Data Structures & Algorithms, LeetCode, Codeforces, Competitive Programming)
     - 🐍 **Python & Programming** (Python, Coding, Software Engineering, Web Dev, IT)
     - 🧩 **IT / Math Problem Solving** (Puzzles, Logic, Aptitude)
     - 🎓 **Study Motivation** (Study Motivation, Focus, Deep Work)
     - 🎵 **Music & Songs** (Lofi, Classical, Chill Beats, BGM)
   - Automatically hides storytimes, vlogs, gaming, drama, reaction, and random entertainment videos.

2. **Social Media Blocker**:
   - Blocks **Instagram, TikTok, Twitter/X, Facebook, and Reddit** when Study Mode is active.

3. **25-Minute Pomodoro Focus Timer**:
   - Built-in timer with digital display and visual SVG progress ring.
   - Background alarms and desktop notifications when study sessions finish.

4. **Study Mode Toggle**:
   - Real-time switch to turn Study Mode ON or OFF instantly.

---

## 🚀 How to Install

### Arc Browser / Google Chrome:
1. Clone this repository:
   ```bash
   git clone https://github.com/samriddhipyakurel666/youtube-study-focus-extension.git
   ```
2. Open `arc://extensions` or `chrome://extensions` in your browser.
3. Turn **ON** **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the `youtube-study-focus-extension` folder.
6. Open YouTube and start studying distraction-free!
